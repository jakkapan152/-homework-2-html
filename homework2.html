เหตุผลที่อยากเรียน Full Stack Web Development

ผมอยากเรียน Full Stack Web Development เพราะสนใจการสร้างเว็บไซต์ และอยากเข้าใจการทำงานของเว็บไซต์ให้ครบทั้งส่วนหน้าบ้าน (Front-end) และส่วนหลังบ้าน (Back-end) เพื่อให้สามารถสร้างเว็บไซต์ที่ใช้งานได้จริง รวมถึงนำความรู้ไปต่อยอดในการเรียนและการทำงานในอนาคต

ความคาดหวังต่อวิชานี้

ผมคาดหวังว่าจะได้เรียนรู้การสร้างเว็บไซต์ตั้งแต่พื้นฐาน เข้าใจการทำงานของ HTML, CSS และ JavaScript รวมถึงการเชื่อมต่อกับระบบหลังบ้านและฐานข้อมูล และสามารถนำความรู้ที่ได้ไปพัฒนาเว็บไซต์ด้วยตนเองได้

จุดอ่อนที่ต้องพัฒนาและแนวทางการพัฒนา

จุดอ่อนของผมคือยังมีประสบการณ์ในการเขียนโปรแกรมไม่มาก และบางครั้งยังไม่มั่นใจเมื่อต้องแก้ไขข้อผิดพลาดของโค้ด แนวทางการพัฒนาคือฝึกเขียนโปรแกรมอย่างสม่ำเสมอ ทดลองทำแบบฝึกหัดด้วยตนเอง ทบทวนบทเรียน และศึกษาวิธีแก้ไขข้อผิดพลาดเพื่อเพิ่มทักษะและความมั่นใจ

เว็บไซต์ที่ชื่นชอบ

เว็บไซต์ที่ผมชื่นชอบคือ YouTube เพราะสามารถค้นหาความรู้ เรียนรู้ทักษะใหม่ ๆ ผ่านวิดีโอ และรับชมเนื้อหาที่สนใจได้
